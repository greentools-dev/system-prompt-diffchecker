Privacy & Security Guarantee

System prompts are confidential intellectual property containing proprietary persona definitions, security guardrails, and tool specifications. This diff engine executes 100% locally in your web browser. Nothing is ever sent to or processed by remote APIs.

Frequently Asked Questions

Why does prompt regression happen?

When developers add new edge-case instructions to an LLM prompt, subtle changes in instruction order or conflicting negative constraints can degrade model adherence elsewhere. Visual diffing guarantees you catch unintended deletions.

How accurate is the token count estimation?

The estimator models standard Byte-Pair Encoding (BPE) tokenizers used by GPT-4 and Claude 3.5, estimating 1 token per ~4 English characters or ~0.75 words with punctuation weighting.

Can I switch between word-level and line-level diffs?

Yes. Use the Diff Granularity selector to switch between pinpoint word-by-word differences and high-level line-by-line block changes.

Does this tool work completely offline?

Yes. All diffing routines run locally inside your browser memory without internet access.
